## ใช้ยังไง (วันละครั้ง)

```
cd "C:\Users\ACER\Ai Agen\forex-ai-demo\promo\factory"
python make_posts.py 5
```

ได้ของครบชุดใน `out/วันที่วันนี้/`
- รูป `.png` ขนาด 1080×1350 พร้อมโพสต์ (ไม่ต้องแต่งต่อ)
- `captions.txt` — แคปชั่นของทุกโพสต์ ก๊อปวางได้เลย
- `plan.md` — ตารางว่าโพสต์ไหนลงที่ไหน เวลาไหน

**ไม่กินโทเคน AI เลยสักตัว** เป็น Python + Chrome ล้วน จะรันกี่รอบก็ได้

## กฎที่ระบบบังคับให้เอง

- **ไม่ซ้ำของเดิม** — จำทุกคู่ที่เคยใช้ไว้ใน `used.json` ไม่หยิบซ้ำจนกว่าคลังจะหมด (ตอนนี้ 300 แบบ)
- **วันเดียวกันหน้าตาไม่ซ้ำ** — 5 โพสต์ต่อวันใช้คนละแม่แบบ
- **ลงคนละที่** — โพสต์ 5 ชิ้นถูกจ่ายไปคนละช่องทางตาม `CHANNELS` ห้ามยิงกลุ่มเดียว 5 ครั้ง เดี๋ยวโดนแอดมินเตะ

## อยากได้เยอะขึ้น/แปลกขึ้น แก้ที่ `content.py` ไฟล์เดียว

| แก้อะไร | ผลที่ได้ |
|---|---|
| เพิ่มร้านใน `SHOPS` | +6 โพสต์ต่อร้านที่เพิ่ม (คูณกับปัญหา) |
| เพิ่มปัญหาใน `PAINS` | +10 โพสต์ต่อปัญหาที่เพิ่ม (คูณกับร้าน) |
| แก้ `PRICE` | เปลี่ยนราคาทุกโพสต์พร้อมกัน ไม่ต้องไล่แก้ทีละรูป |
| เพิ่มแคปชั่นใน `CAPTIONS` | ข้อความหลากหลายขึ้น ไม่ให้คนจำได้ว่าก๊อปวาง |
| เพิ่มกลุ่มใน `CHANNELS` | โพสต์ได้มากกว่า 5 ชิ้น/วัน แบบไม่ต้องยิงซ้ำกลุ่มเดิม |

จำนวนโพสต์ที่เป็นไปได้ = แม่แบบ × ร้าน × ปัญหา = **5 × 10 × 6 = 300**
เติมร้านอีก 5 กับปัญหาอีก 4 → กลายเป็น 5 × 15 × 10 = **750**

## แม่แบบที่มี (`templates/`)

| ไฟล์ | หน้าตา | เหมาะกับ |
|---|---|---|
| `receipt.html` | ใบเสร็จกระดาษ | กลุ่มแม่ค้า, เพจ |
| `before_after.html` | ก่อน–หลัง + สกรีนช็อตระบบจริง | ทุกกลุ่ม (รวมสายเทค) |
| `chat.html` | จอแชทลูกค้ารุมถาม | แม่ค้า, เพจ, TikTok |
| `gp.html` | เทียบตัวเลขค่า GP รายเดือน | แม่ค้า, เพจ, TikTok |
| `checklist.html` | เช็กลิสต์ 5 ข้อ | แม่ค้า, เพจ, TikTok |

แก้ดีไซน์ = แก้ HTML ตรงๆ ได้เลย ตัวแปรอยู่ในรูป `{{ชื่อ}}`
ถ้าลืมใส่ค่าให้ตัวแปรไหน สคริปต์จะ **ล้มทันที** ไม่ปล่อยรูปที่มี `{{FOOT2}}` โผล่ออกไปให้ลูกค้าเห็น
