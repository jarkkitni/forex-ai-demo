ตอนเปิดบัญชี Google Ads ครั้งแรก ระบบจะพาเดินผ่านหน้าตั้งค่าที่ดูเหมือนช่วยเรา แต่ค่าตั้งต้น (default) หลายตัวออกแบบมาให้ใช้งบได้เร็วที่สุด ไม่ใช่ให้ได้ลูกค้าคุ้มที่สุด บทความนี้รวม 7 จุดที่ผมไล่ปิดก่อนกดเผยแพร่แคมเปญ Search แรกของตัวเอง (แคมเปญรับทำแชทบอท งบ ฿100–150/วัน)

💡 ทุกข้อในบทความนี้เป็นการตั้งค่าที่ทำครั้งเดียวก่อนเปิดแคมเปญ ปิดไว้ตั้งแต่แรกง่ายกว่ามาแก้หลังจากเสียงบไปแล้ว

1. หลุดเข้า Smart campaign แทน Expert Mode

หน้าแรกของ Google Ads จะพาสร้าง Smart campaign อัตโนมัติ ซึ่งสะดวก แต่มองไม่เห็นคีย์เวิร์ดและคำค้นจริง ที่ทำให้โฆษณาขึ้น คุณจะไม่รู้เลยว่าจ่ายเงินให้คนที่ค้นคำอะไร

วิธีเลี่ยง: หาลิงก์สลับไป Expert Mode (มักอยู่ล่างสุดของหน้าเลือกเป้าหมาย) แล้วเลือกสร้างบัญชีโดยยังไม่สร้างแคมเปญ ชื่อปุ่มเปลี่ยนบ่อย แต่ความหมายคือ "สร้างบัญชีอย่างเดียว"

2. Auto-apply recommendations เปิดอยู่

Google มีคำแนะนำที่ใช้ได้เองอัตโนมัติ เช่น เพิ่มคีย์เวิร์ด เปลี่ยน match type เป็น broad หรือเพิ่มงบ ถ้าเปิดไว้ ระบบจะแก้แคมเปญเองแบบเงียบๆ

วิธีเลี่ยง: ไปที่ Recommendations → Auto-apply แล้วยกเลิกทุกข้อ คำแนะนำยังดูได้ตามปกติ แค่ต้องกดยอมรับเอง

3. Search partners และ Display Network ถูกติ๊กมาให้

ตอนสร้างแคมเปญ Search ช่อง Networks จะติ๊ก Search partners และ Display Network มาให้ Display คือโฆษณาบนเว็บและแอปทั่วไป ได้คลิกถูกแต่ส่วนมากไม่ใช่คนที่กำลังหาบริการ (รวมถึงคลิกพลาดจากเกมในมือถือ)

วิธีเลี่ยง: เหลือแค่ Google Search ตอนเริ่ม พอมีข้อมูลแล้วค่อยทดลองเปิดเพิ่มทีละอย่าง

4. Broad match เป็นค่าตั้งต้นของคีย์เวิร์ด

พิมพ์คีย์เวิร์ดลงไปเฉยๆ จะเป็น broad match ซึ่งให้ Google ตีความกว้างมาก เช่นคำว่า "รับทำ line bot" อาจทำให้โฆษณาขึ้นกับคำว่า "line สติกเกอร์ฟรี"

วิธีเลี่ยง: ใส่เครื่องหมายเองทุกคำ

  • "รับทำ line bot" = phrase match (คำค้นต้องมีความหมายนี้อยู่)
  • [รับทำ line bot] = exact match (ความหมายเดียวกันเท่านั้น)

คำที่ราคาต่อคลิกแพง ใช้ exact อย่างเดียว

5. Location เป็น "Presence or interest"

ค่าตั้งต้นแสดงโฆษณาให้ทั้งคนที่อยู่ในประเทศไทย และคนที่สนใจประเทศไทย ซึ่งรวมคนต่างประเทศที่วางแผนเที่ยวไทยด้วย ถ้าขายบริการให้ร้านในไทยก็เสียงบเปล่า

วิธีเลี่ยง: ในตัวเลือก Location ขั้นสูง เลือก Presence (คนที่อยู่หรืออยู่ประจำในพื้นที่)

6. ไม่มี negative keyword ตั้งแต่วันแรก

คำค้นที่ดูเกี่ยวข้อง หลายคำมาจากคนที่ไม่ได้จะจ้างเลย ผมแบ่ง negative keyword ที่ใส่ตั้งแต่วันแรกเป็นกลุ่มแบบนี้

กลุ่มตัวอย่างคำ
อยากทำเอง / อยากเรียนฟรี, สอน, วิธีทำ, ทำเอง, คอร์ส, tutorial
นักพัฒนาpython, github, sdk, webhook
คนหางานสมัครงาน, เงินเดือน, หางาน
บริการอื่นของแบรนด์เดียวกันสติกเกอร์, line man, line pay, ดาวน์โหลด
คิวราชการ/โรงพยาบาล (ถ้ายิงคำว่า "ระบบจองคิว")โรงพยาบาล, ใบขับขี่, พาสปอร์ต, ประกันสังคม
⚠️ ระวังใส่คำที่กว้างเกินไป เช่น "excel" หรือ "ฟรีแลนซ์" ลูกค้าจริงก็พิมพ์คำพวกนี้ ("ส่งข้อมูลลง Excel", "จ้างฟรีแลนซ์ทำบอท") ใส่แล้วจะตัดลูกค้าดีทิ้งไปด้วย

หลังเปิดแคมเปญ ให้เปิดรายงาน Search terms ทุกเช้า คำไหนไม่ใช่คนจ้างให้เพิ่มเป็น negative นี่คือการปรับแคมเปญที่ได้ผลที่สุดในช่วงแรก

7. ยิงแอดโดยยังไม่มี conversion tracking

ถ้าไม่วัดว่าคลิกไหนกลายเป็นคนกรอกฟอร์มหรือโทรมา จะเหลือให้ดูแค่ CTR และจำนวนคลิก คำที่ CTR สูงอาจเป็นคำที่มีคำว่า "ฟรี" ซึ่งคลิกเยอะแต่ไม่มีใครจ้าง กลายเป็นขาดทุนที่ตัวเลขดูดี

วิธีเลี่ยง: ติด conversion ก่อนคลิกแรก ดูวิธีทีละขั้นที่ ติด Conversion Tracking ให้ฟอร์มบนเว็บ

แถม: สองเรื่องที่ทำให้โฆษณาไม่วิ่ง

  • ยอดค้างชำระจากบัญชีเก่า — ถ้าเคยมีบัญชี Google Ads ที่ค้างจ่าย ควรเคลียร์ก่อน เพราะ Google ผูกยอดค้างกับตัวบุคคลและวิธีชำระเงิน
  • เครื่องหมายการค้าในข้อความโฆษณา — ชื่อแบรนด์ของคนอื่น (เช่น LINE) ในหัวข้อโฆษณาอาจถูกจำกัดการแสดงผล ถ้าโดน ให้เปลี่ยนเป็นคำทั่วไป เช่น "ไลน์" หรือ "แชทบอท" (ใช้เป็นคีย์เวิร์ดได้ตามปกติ)

อีกเรื่องคือ อย่าแก้แคมเปญใหญ่ๆ ทุกวันในช่วงแรก การเปลี่ยนกลยุทธ์ bid ทำให้ระบบเริ่มเรียนรู้ใหม่ ให้รอดูข้อมูลอย่างน้อย 7 วันก่อนตัดสินใจ
