LINE Notify เคยเป็นวิธีที่ง่ายที่สุดในการส่งแจ้งเตือนเข้า LINE ตัวเอง แค่ขอ token แล้วยิง HTTP ครั้งเดียว แต่ LINE ปิดบริการ LINE Notify ไปแล้วตั้งแต่ 31 มีนาคม 2025 ระบบเก่าที่ยังเรียกใช้อยู่จึงส่งไม่ออกทั้งหมด บทความนี้บอกวิธีย้ายไปใช้ Messaging API แทน และเรื่องที่ต่างไปจากเดิมที่ต้องรู้ก่อนย้าย

อาการของระบบที่ยังใช้ LINE Notify

  • แจ้งเตือนออเดอร์ / แจ้งเตือนเซิร์ฟเวอร์ล่ม / แจ้งเตือนจากกล้องวงจรปิด เงียบไปเฉยๆ
  • ถ้าระบบไม่ได้เช็คผลตอบกลับ จะไม่มีใครรู้เลยว่าส่งไม่ออก (เรื่องนี้อันตราย ดู ระบบตายเงียบ)

ตัวแทน: LINE Official Account + Messaging API

วิธีที่ LINE แนะนำคือสร้าง LINE Official Account (บัญชีฟรีก็ได้) เปิด Messaging API แล้วให้บอทเป็นคนส่งข้อความหาคุณ

  1. สร้าง LINE OA และเปิดใช้ Messaging API ใน LINE Official Account Manager
  2. เข้า LINE Developers Console → channel ของบอท → ออก Channel access token
  3. เพิ่มบอทเป็นเพื่อนด้วยบัญชี LINE ของคุณเอง (หรือเชิญเข้ากลุ่มที่ต้องการให้แจ้งเตือน)
  4. หา User ID ของคุณ (หรือ Group ID ของกลุ่ม) เพื่อใช้เป็นปลายทาง — อย่าสับสนกับ Basic ID ของบอท ดู User ID กับ Basic ID ต่างกันยังไง
  5. ส่งข้อความด้วย push message

โค้ดเทียบ: ก่อนและหลัง

แบบเดิม (LINE Notify ใช้ไม่ได้แล้ว)

requests.post("https://notify-api.line.me/api/notify",
    headers={"Authorization": f"Bearer {NOTIFY_TOKEN}"},
    data={"message": "มีออเดอร์ใหม่"})

แบบใหม่ (Messaging API push)

import os, requests

def line_push(text: str) -> None:
    r = requests.post(
        "https://api.line.me/v2/bot/message/push",
        headers={"Authorization": f"Bearer {os.environ['LINE_CHANNEL_TOKEN']}"},
        json={"to": os.environ["LINE_ADMIN_USER_ID"],
              "messages": [{"type": "text", "text": text[:5000]}]},
        timeout=10,
    )
    r.raise_for_status()   # ส่งไม่ออกต้องรู้ อย่าปล่อยเงียบ

line_push("มีออเดอร์ใหม่ #1024 ยอด 1,250 บาท")

ข้อความ text หนึ่งข้อความยาวได้ไม่เกิน 5,000 ตัวอักษร โค้ดข้างบนจึงตัดไว้ก่อน

เก็บ token และ User ID ไว้ใน environment variable เสมอ อย่าเขียนลงในโค้ดตรงๆ (ดู กัน API key หลุดขึ้น GitHub)

สิ่งที่ต่างจาก LINE Notify

  • มีโควตาข้อความ — push message นับโควตารายเดือนของ LINE OA แพ็กเกจฟรีส่งได้จำกัด ถ้าแจ้งเตือนถี่ต้องคิดเรื่องนี้ (รายละเอียดใน โควตา LINE OA)
  • ผู้รับต้องเป็นเพื่อนกับบอท — ถ้าบล็อกบอท ข้อความจะไม่ถึง
  • ส่งเข้ากลุ่มได้ — เชิญบอทเข้ากลุ่ม แล้วใช้ Group ID เป็นปลายทาง (Group ID ได้มาจาก webhook event ตอนบอทเข้ากลุ่มหรือมีคนพิมพ์ในกลุ่ม)
  • ส่งข้อความสวยขึ้นได้ — ใช้ Flex Message ทำการ์ดแจ้งเตือนที่มีปุ่มกดได้ เช่น ปุ่ม "ดูออเดอร์"

ประหยัดโควตา: รวบแจ้งเตือน

ถ้าระบบเดิมยิงแจ้งเตือนทุกเหตุการณ์ เช่น ทุกออเดอร์ ทุก error ย้ายมาแล้วโควตาหมดเร็ว ทางแก้ที่ใช้บ่อย

  • แจ้งทันทีเฉพาะเรื่องด่วน เรื่องที่รอได้ให้รวบเป็นสรุปรายชั่วโมงหรือรายวัน
  • error เดิมซ้ำๆ แจ้งครั้งเดียว แล้วรอ 30 นาทีก่อนแจ้งซ้ำ
  • แจ้งเตือนที่ไม่ต้องอ่านบนมือถือ ย้ายไปอีเมลหรือ Discord webhook แทน

ถ้าใช้ n8n อยู่ ใช้ HTTP Request node ยิง endpoint เดียวกันนี้ได้เลย ไม่ต้องลงอะไรเพิ่ม (ดู n8n ส่งข้อความเข้า LINE)
