เว็บที่เพิ่งเปิด Google ยังไม่รู้จัก ต้องรอให้มันเจอเอง ซึ่งอาจนานหลายสัปดาห์ Google Search Console ช่วยให้เราบอก Google ตรงๆ ว่ามีหน้าอะไรบ้าง และดูได้ว่าหน้าไหนติดปัญหาอะไร บทความนี้คือสิ่งที่ผมทำกับเว็บใหม่ทุกเว็บ เรียงตามลำดับ

1. เพิ่ม property และยืนยันว่าเป็นเจ้าของ

มีสองแบบ

แบบครอบคลุมยืนยันด้วย
Domainทุก subdomain ทั้ง http และ httpsเพิ่ม TXT record ใน DNS
URL prefixเฉพาะ URL ที่ขึ้นต้นตามที่ใส่ไฟล์ HTML, meta tag, Google Analytics ฯลฯ

ถ้าจัดการ DNS ได้ ใช้แบบ Domain ครอบคลุมที่สุด ถ้าใช้แบบไฟล์ HTML (เช่น google1234abcd.html) อย่าลบไฟล์นั้นทีหลัง Google ตรวจซ้ำเป็นระยะ ลบแล้วจะหลุดสถานะเจ้าของ ผมเขียนคอมเมนต์ "ห้ามลบ" ไว้ในโค้ดตรงที่เสิร์ฟไฟล์นี้ กันตัวเองลบตอนเก็บกวาดโค้ด

ถ้าย้ายโดเมน ต้องเพิ่ม property ใหม่ของโดเมนใหม่ด้วย property เดิมไม่ตามไปเอง

2. ทำ sitemap.xml ให้ถูก

sitemap คือรายการ URL ที่อยากให้ Google รู้จัก รูปแบบพื้นฐาน

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://example.com/</loc><lastmod>2026-10-24</lastmod></url>
  <url><loc>https://example.com/blog/hello</loc><lastmod>2026-10-20</lastmod></url>
</urlset>

กับดัก: lastmod ที่เปลี่ยนทุกครั้ง

ถ้าสร้าง sitemap ด้วยโค้ดแล้วใส่ lastmod เป็นเวลาปัจจุบัน ทุกครั้งที่มีคนเปิด sitemap วันที่จะขยับทั้งที่เนื้อหาไม่ได้เปลี่ยน Google รู้ว่าค่านี้ไม่น่าเชื่อถือ แล้วจะเลิกใช้ lastmod ของเว็บเรา ให้ใส่วันที่แก้เนื้อหาจริงครั้งล่าสุดของแต่ละหน้า

ใส่เฉพาะหน้าที่อยากให้ติดอันดับ

  • ไม่ใส่หน้าที่ redirect ไปที่อื่น (ใส่ปลายทางแทน)
  • ไม่ใส่หน้า noindex เช่น หน้าแอดมิน หน้าเดโมสำหรับลูกค้ารายเดียว
  • ไม่ใส่หน้าที่เนื้อหาซ้ำกับหน้าอื่น

บอกตำแหน่ง sitemap ใน robots.txt ด้วย

User-agent: *
Allow: /
Disallow: /admin
Sitemap: https://example.com/sitemap.xml

3. ส่ง sitemap และขอ index หน้าสำคัญ

  1. เมนู Sitemaps → ใส่ sitemap.xml → ส่ง ควรขึ้นสถานะสำเร็จพร้อมจำนวน URL ที่พบ
  2. เมนูตรวจสอบ URL → ใส่ URL หน้าแรก → ขอการจัดทำดัชนี (ทำกับหน้าสำคัญไม่กี่หน้าพอ มีโควตาต่อวัน)

ส่ง sitemap ครั้งเดียวพอ Google จะกลับมาอ่านเองเป็นระยะ เวลาเพิ่มหน้าใหม่แค่อัปเดตไฟล์ ไม่ต้องส่งใหม่

4. อ่านรายงานให้เป็น

Pages (การจัดทำดัชนี)

บอกว่าหน้าไหนถูก index และหน้าไหนไม่ถูก พร้อมเหตุผล เหตุผลที่ควรดูเป็นพิเศษ

  • Duplicate, Google chose different canonical — Google คิดว่าหน้านี้ซ้ำกับอีกหน้า ตรวจ canonical
  • Crawled – currently not indexed — Google เห็นแล้วแต่ยังไม่เก็บ เว็บใหม่เจอบ่อย ปรับเนื้อหาให้มีประโยชน์ขึ้นและรอ
  • Excluded by noindex — ถ้าเป็นหน้าที่ควรติดอันดับ แปลว่ามี noindex ค้าง

Performance

ดูคำค้นที่ทำให้เว็บแสดงผล จำนวนคลิก และอันดับเฉลี่ย เว็บใหม่จะมีข้อมูลน้อยในช่วงแรก สิ่งที่น่าดูคือคำที่มีการแสดงผลเยอะแต่คลิกน้อย อาจปรับ title ให้ตรงกับคำนั้นมากขึ้น

ใช้เวลานานแค่ไหน

หลังส่ง sitemap Googlebot มักเริ่มเข้ามาภายในไม่กี่วัน แต่การติดอันดับใช้เวลานานกว่านั้นมาก โดยเฉพาะเว็บใหม่ ระหว่างรอ ให้ดึงคนอ่านจากช่องทางอื่น เช่น แชร์บทความในเพจหรือกลุ่มที่เกี่ยวข้อง
